# Athena Greek Coffee House

A responsive, accessible landing page for a traditional Greek coffee house. Built with semantic HTML, modern CSS, and vanilla JavaScript.

## Features

- White/light theme by default with a persistent theme toggle
- Responsive desktop, tablet, and mobile layouts
- Keyboard-friendly navigation and visible focus states
- Reduced-motion support
- Original project-local hero artwork inspired by the supplied design references

Open `index.html` in a browser or serve the folder with any static web server.
